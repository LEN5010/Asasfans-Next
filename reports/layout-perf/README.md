## 保留的实现结论

- 二创各类型按内容自然结束，宽屏瀑布流不跨类型等高；宽度变化保持可见区域 40% 处的作品。列数不再因正文宽度跨过 760 而突然减少。
- 今日统一为一个 `CustomScrollView`：日程与继续挑选为顶部摘要，二创满宽，其后切片与历史；日程始终纵排，不再左右分栏。
- 底部导航位于外壳 `bottomNavigationBar`，`extendBody` 保持开启；提示条在其上方，键盘焦点定位扣除状态栏与导航遮挡。
- 列表缩略图解码上限 2 MPx / 8192 px；详情与完整查看保留 16 MPx。封面单子组件首次淡入修复缩放时的 disposed image 异常。
- 玻璃饱和度 1.0、光晕 0.4、浅/深 tint 0.50/0.40；只在可操作区域使用悬停与按压反馈。
- macOS/Windows 标题栏跟随应用明暗；Windows 只验证到 CI 编译，未验证真实运行。
