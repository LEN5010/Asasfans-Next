# 首次打开说明

这个版本用的是 ad-hoc 签名，没有经过 Apple 公证，所以第一次打开需要多一步。之后就和普通应用一样，双击即可。

## 安装

把 `Asasfans Next.app` 拖进 `Applications` 文件夹。

## 第一次打开

**不要直接双击**，否则系统会提示无法验证开发者。正确做法：

1. 在「应用程序」里找到 Asasfans Next
2. 按住 Control 点击图标（或右键），选「打开」
3. 弹窗里再点一次「打开」

只需要做这一次，之后正常双击就行。

如果弹窗里没有「打开」按钮，去 系统设置 → 隐私与安全性，往下翻会看到一条关于 Asasfans Next 的提示，点「仍要打开」。

## 为什么要这样

macOS 的 Gatekeeper 会拦截没有经过 Apple 公证的应用。公证需要 Apple Developer Program 账号（99 美元/年），本项目目前没有。

免费 Apple ID 解决不了这个问题：它签出的证书 7 天就过期，而且只在已经信任它的机器上有效，是给开发阶段真机调试用的，不适合分发。

Ad-hoc 签名虽然不能免除上面那一步，但能让系统把应用识别为「开发者身份不明」而不是「已损坏」，后者看起来像是文件下载坏了。

## 如果提示「已损坏」

正常情况不该出现。真遇到了，通常是下载时被打上了隔离标记，终端执行：

```bash
xattr -dr com.apple.quarantine "/Applications/Asasfans Next.app"
```

然后重新打开。
