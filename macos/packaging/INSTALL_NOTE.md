# macOS 开发包说明

当前只交付开发构建，不是经过 Apple 公证的正式发行包。具体构建提交、模式和已知缺口以交付目录中的说明为准；旧包不代表最新源码。

- 保留完整 `.app` 目录和可执行权限，不只拷贝内部主程序。CI 使用 tar 保存 Apple 包结构。
- 按交付说明打开应用；若系统拒绝打开，先核对包来源和对应构建，再按本机系统提示处理。不要把递归删除隔离属性当作默认安装步骤。
- 正式 Developer ID 签名、公证、分发身份和系统兼容性另行验收，不从本机开发构建成功推断。

当前开发不要求搬入 Applications，也不自动安装、启动或调整系统安全设置。
