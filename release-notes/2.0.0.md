# Asasfans Next 2.0.0

2.0 是主要使用流程的一次重构：保留嘉然应援粉，重新组织视频、资料库、账号和社区工具，让浏览与本地内容管理更直接。

## 新界面与导航

- 以 Kotlin + Compose 重建主界面，采用紧凑胶囊控件与媒体网格。
- 五栏调整为「今日 / 发现 / 工具 / 资料库 / 我的」，宽屏使用侧栏导航。
- 居中的粉色工具按钮打开图标抽屉，整合录音棚、日历、动态站、社区导航、Wiki、字幕等 13 个工具。
- 恢复原版嘉然粉 `#E799B0`，配合深玫瑰色文字，提供浅色与深色主题。
- 精简普通页面的说明文字，内容和操作优先。

## 视频浏览与 UP 主页

- 今日最新视频和发现列表改为自动信息流，接近底部即可继续加载。
- 支持下拉刷新、追加失败保留内容、原页重试和缓存续载。
- 对重复结果和大量过滤内容进行有界补页，避免持续空转请求。
- 新增 UP 主页：头像、昵称、简介、认证信息、本地订阅和自动分页投稿。
- 点击视频卡片、播放器中的 UP 区域或订阅列表即可进入主页；右上角可打开 B 站空间。
- 订阅管理移至「我的」，账号卡片的订阅数量也可直接进入。

## 账号与播放

- 新增应用内 B 站官方网页登录，手机可使用官方页面提供的密码或短信等方式，不必给自己扫码。
- 保留二维码登录，并兼容 B 站新的官方扫码地址。
- 网页登录态验证成功后保存到现有加密存储；离开登录页取消当前操作，不读取或保存密码。
- 网络验证失败不直接清除已有账号；退出未完成时保留重试入口。
- 新播放器提供分 P、清晰度、倍速、全屏、播放进度恢复，以及只读评论。

## 本地资料与升级

- 资料库统一组织稍后看、收藏夹、观看历史和书签。
- 使用 Room 与 DataStore 管理新版本地数据和偏好。
- 兼容旧版 v1–v4 数据库，修复 v4 旧库导致的启动失败。
- 保留原始旧库，迁移订阅与屏蔽规则；旧追更缓存和已读状态保存在恢复记录中，不误写为观看历史。
- 保持应用标识 `asasfans.next` 和现有签名配置；使用同一发布签名可覆盖升级，无需卸载或清除数据。

## 本版范围

- 订阅是本应用内的订阅，不会修改 B 站账号关注；完整的订阅更新聚合仍在后续重构范围内。
- 评论保持只读；音乐、日历等社区功能仍通过内置网页提供。
- B 站登录、投稿与播放仍受官方接口、账号权限及风控影响；长视频、高画质和全部设备生命周期场景尚未完成完整验证。

版本：`2.0.0` · versionCode：`200` · Android 7.0 及以上。
