# Asasfans Next 3.1.0

- 新增音乐：播放录音棚收录的歌回音频，可按成员、年份筛选和搜索歌名；歌曲可收藏，可一键去 B 站搜切片或录播。手机上迷你播放器在各页面底部，电脑上播放条在音乐页底部，切到其他页面收进左侧栏。
- 日历新增成员关注和开播提醒：关注成员后她的直播与星标场次一起提醒，可设提前 0 / 5 / 15 / 30 分钟；关注日程页列出接下来 30 天的场次。
- 二创、动态、小说的筛选面板统一样式，成员项带头像；选项与背景对比度加深。
- 悬浮返回入口移到「我的」页（仅 Android）。
- 修复从后台回来时内容列表被清空重载。

安装：Android 可覆盖更新；Windows 推荐下载 `-windows-x64-setup.exe`。macOS 首次打开请右键点应用 → 打开；iOS 需自行签名安装。
