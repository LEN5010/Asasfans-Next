# Asasfans Next 3.0.0-beta.1

3.0 用 Flutter 从头重写，同一套代码跑在 Android、iOS、macOS 和 Windows 上。这是第一个预发布版，欢迎试用并在 [Issues](https://github.com/LEN5010/Asasfans-Next/issues) 反馈问题。

## 栏目

- **今日**：本周日程条（每个成员一个色点）、随机二创、最新切片、历史上的今天。
- **内容**：二创、视频、动态、小说四个频道。二创可以按成员和分类筛选；视频分全部 / 切片 / 录播，点开去 B 站看；动态保留表情、图片、视频和转发；小说可以直接阅读全年龄作品。
- **随机二创**：二创频道搜索框旁边的按钮打开，往下滑会一直抽新的，同一页不会重复。
- **日历**：日 / 周 / 月视图，按成员和类型筛选，可以关注日程，日程有变动时在应用里提醒。
- **我的**：收藏、稍后看、浏览记录、继续观看、时间书签、本地订阅、内容规则、备份与恢复。
- **工具**：底栏右侧的圆钮，录音棚、日历、动态站、枝网查重、Wiki 等社区站点都在里面。

## 和 2.0 相比

- 界面整体重做：成员应援色贯穿日程、标签和头像，二创详情页和看图页重新设计，手机用悬浮底栏，宽屏用侧栏。
- 新增 **检查更新**：启动时会查一次 GitHub 上有没有新版本，也可以在 我的 → 应用 → 检查更新 手动查。
- 应用内 B 站登录、内置播放器、评论和 UP 主页已移除，视频和 UP 主页都跳到 B 站打开。
- 2.0 的收藏、订阅、屏蔽规则和偏好 **不会迁移** 到 3.0，需要重新添加。3.0 之后的版本之间会保留你的资料，也可以用 我的 → 备份与恢复 导出。

## 安装

- **Android**（7.0 及以上）：下载 `-android.apk` 安装。签名和 2.0 相同，可以直接覆盖安装；旧版资料不会被读取，也不会被删除。
- **Windows**（10 及以上，x64）：解压 `-windows-x64.zip`，运行里面的 `asasfans_next.exe`。
- **macOS**（12 及以上）：解压 `-macos.zip`。这个包没有经过 Apple 公证，第一次打开请在 Finder 里右键点应用 → 打开；如果提示已损坏，在终端执行 `xattr -dr com.apple.quarantine "/Applications/Asasfans Next.app"` 后再打开。
- iOS 暂不提供安装包。
