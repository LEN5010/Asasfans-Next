# Asasfans Next 3.1.4

- 音乐新增随机播放，歌曲列表、收藏页、播放页和桌面播放条共用随机模式，队列按实际播放顺序显示。
- 播放页随窗口高度调整封面，歌曲卡和迷你播放器的播放按钮更紧凑；以 60% 音量作为响度基准，保留正向增益。
- 新增活动专题、二创页活动入口、开屏海报和公告列表；「此间共鸣」物料可按分类和关键词查找，周报原帖入口更清晰。
- 新增按平台显示的重要更新提示、反馈与帮助入口。
- 修复窄屏播放按钮超宽、队列达到 200 首后仍可追加歌曲，以及已读状态保存失败时重要公告无法展示的问题。

安装：Android 可覆盖更新；Windows 推荐下载 `-windows-x64-setup.exe`。macOS 首次打开请右键点应用 → 打开；iOS 需自行签名安装。
